## R语言地图绘制 / R Map Visualization

本仓库包含了使用R语言绘制地图的示例代码和详细指南。

This repository contains example code and detailed guide for drawing maps using R language.

### 文件 / Files

- **map_visualization.R** - R地图绘制脚本 / R map visualization script
- **MAP_GUIDE.md** - 详细的使用指南 / Detailed usage guide

### 快速开始 / Quick Start

```r
# 安装必需的包 / Install required packages
install.packages(c("ggplot2", "maps"))

# 运行脚本 / Run the script
source("map_visualization.R")
```

查看 [MAP_GUIDE.md](MAP_GUIDE.md) 获取完整文档。
